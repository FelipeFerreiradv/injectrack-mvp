# Política de Privacidade e LGPD - InjecTrack

## Consentimento de Privacidade

Ao usar o InjecTrack, você concorda com esta Política de Privacidade e com o tratamento dos seus dados pessoais conforme descrito abaixo.

## Dados Coletados

### Dados Pessoais
- Nome completo
- E-mail
- Data de nascimento
- Sexo
- Altura e peso

### Dados de Saúde
- Tipo de medicação (Ozempic, anabolizantes, etc.)
- Registros de injeções
- Logs diários (proteínas, fibras, água)
- Efeitos colaterais
- Fotos de injeções (armazenadas de forma criptografada)

### Dados de Uso
- Histórico de uso do aplicativo
- Preferências de notificação
- Dados de assinatura

## Finalidade do Tratamento

Seus dados são utilizados para:
- Fornecer funcionalidades do aplicativo
- Personalizar sua experiência
- Melhorar nossos serviços
- Enviar notificações (se autorizado)
- Processar pagamentos de assinatura

## Segurança dos Dados

- **Criptografia**: Dados sensíveis são criptografados em repouso e em trânsito
- **Armazenamento**: Dados armazenados em servidores seguros
- **Acesso**: Apenas pessoal autorizado tem acesso aos dados
- **Backup**: Backups regulares com criptografia

## Compartilhamento de Dados

Seus dados **não são compartilhados** com terceiros, exceto:
- Prestadores de serviço (hospedagem, pagamento) sob contrato de confidencialidade
- Quando exigido por lei ou ordem judicial

## Seus Direitos (LGPD)

Você tem direito a:
- **Acesso**: Solicitar acesso aos seus dados
- **Correção**: Corrigir dados incorretos
- **Exclusão**: Solicitar exclusão dos seus dados
- **Portabilidade**: Exportar seus dados
- **Revogação**: Revogar consentimento a qualquer momento
- **Oposição**: Opor-se ao tratamento de dados

## Retenção de Dados

- Dados são mantidos enquanto sua conta estiver ativa
- Após exclusão da conta, dados são removidos em até 30 dias
- Dados podem ser mantidos por período maior se exigido por lei

## Cookies e Tecnologias Similares

O aplicativo pode usar tecnologias para melhorar a experiência:
- Armazenamento local (offline-first)
- Analytics (anonimizado)

## Menores de Idade

O InjecTrack não coleta dados de menores de 18 anos sem consentimento dos pais/responsáveis.

## Alterações nesta Política

Podemos atualizar esta política periodicamente. Notificaremos sobre mudanças significativas.
